# 字の作り方

## 丸め方

BIZ UDゴシック (em 2048 を半分の 1024 にして使う) の字は、輪郭のまま角ごとに円弧を入れます ([fillet.rs](../tools/src/fillet.rs))。

- 出っ張った角は半径 41 (em の 4%)、へこんだ角は半径 12。円弧は 2 次曲線 (曲がりが 60° を超える大きな円弧は 2 本) で近づける
- 辺が短くて半径どおりに入らないときは、辺の半分まで使える半径に小さくする。細い線の端は線の太さの半円になる
- 元の点はそのまま運ぶので、点は角 1 つにつき 2〜3 増えるだけ
- 丸めた輪郭どうしが交わる字 (浚 瀰 礫 騙 など、近い線の角が重なるもの) は、描いた字と同じく格子で丸める

角を残す字は [data/sharp.txt](../data/sharp.txt) (罫線と ■ □、それを元にした ⬛ ⌺ ⛋ ⛝ ⛞ ￭)。

## 元に無い字

| 作り方 | 字 |
| --- | --- |
| 同じ字形を指す | 互換漢字 U+FA6B〜FA6D は元の字へ |
| 部品を組む ([data/parts.txt](../data/parts.txt)) | 囲み文字・分数・漢字 (喼 䃯 𠮷 など)・幅を変える字など |
| 楽器の略記 | 92 区 56〜85 点 (私用領域 U+E2A5〜E2C2) の (vn) (ob) …。半角の字を横 50%・縦 80% にして 1 マスに並べる |
| 描く ([draw.rs](../tools/src/draw.rs)) | 天気・道路・地図の記号など ⛄ ⛅ ⚡ ⛔ ⛩ ⚾ …、字幕の外字 (DRCS) の置き換え先 📱 🔊 📺 |

どの字をどう作ったかはビルドのたびに `build/extras.txt` に出ます。

`parts.txt` は 1 字 1 行で、BIZ UDゴシックの字 (使う輪郭の番号・切り抜く枠) と置く枠を書きます (書き方はファイルの頭)。
元にある字でも書けばこちらが勝ちます。組むのは格子 (em 1024 を 512 マスに) の上で、縮めて細った線は縮めた向きにだけ膨らませて元の太さ (漢字は 84) に戻し、
ほかの字と同じ半径で丸めます ([round.rs](../tools/src/round.rs))。格子から引いた等高線は直線と 2 次曲線に当てはめ直します ([fit.rs](../tools/src/fit.rs))。

カラー絵文字が既定の字 (🅿 ♨ ☎ ⚡ ⛅ ❗ ⁉ など) も白黒の形で入れます。

## 幅と高さ

- 送り幅は半角 512・全角 1024 だけ。どの字が半角かは v2.x と同じ
- BIZ UDゴシックで半角の ½ ▶ ♠ ≈ などは全角にし、v2.x と同じ大きさに広げて線の太さを補う。分数は数字と斜線を全角の大きさに組む。全角の ° は半角にする
- 行の高さは v1.x から同じ (WinAscent 981 / WinDescent 168)。字幕は「永」の墨の上下で縦の位置を決めるので (denpa)、元が替わっても縦の真ん中は変わらない

## palt (全角の英数字を詰める)

番組名・番組説明を表示するときに、放送のデータでは全角のままの英数字を詰めるための OpenType の機能です。
クライアントが有効にしたときだけ効きます (CSS は `font-feature-settings: "palt"`、Android は `fontFeatureSettings`)。字幕・データ放送では使いません。

- 詰めるのは全角の英数字と記号 (U+FF01–FF5E、Ａ ａ ０ ！ （ ． ／ など) だけ。かな・漢字・和文の約物 (「」、。・ 全角の空白など) は詰めない
- 詰め量はビルドのたびに出来た字の墨の枠から出す ([palt.rs](../tools/src/palt.rs))。墨の左右に 80 ずつ残し (字の間は 160)、墨を真ん中に置く。送り幅の下限は 320 (ｉ ． ： ｜ など細い字)
- 墨と余白で全角に届く字 (墨の幅が 864 以上の Ｗ ％ ／ ＼ ＿) は全角のまま
- 既定の送り幅 (hmtx) は変えない。palt を使わなければ見え方は前と同じ
- DFLT・hani・kana・latn のどれからも引ける (記号は前後の字の用字系になるので、和文に挟まれても効く)

## ccmp (2つのコードポイントの字を1字に組む)

JIS X 0213 には、Unicode では2つのコードポイントで表す字が 25 あります (か゚ ㇷ゚ などの半濁点の付いたかな、æ̀ ɔ́ などの発音記号、声調の組 ˩˥ ˥˩)。
denpa の表 (`KANJI_SEQUENCES`) にあるものを、BIZ UDゴシックの ccmp の合字と同じ形の 1 字にします ([ccmp.rs](../tools/src/ccmp.rs))。

- ccmp は既定で効くので、ブラウザもアプリも何もしなくてよい。denpa の字幕は並びを 1 区画にまとめて描く
- 並びの字 (か・U+309A など) もそれぞれ収める (1 字ずつでも描ける)。web フォントでは、並びの字・組んだ字・ccmp をどれも基本のファイル (`denpa-font.woff2`) に入れる (ccmp は 1 つのフォントの中でしか組めない)
- 引ける用字系は palt と同じ

## ヒンティングを持たない理由

字幕・データ放送を描くところは、どれも TrueType の命令を使いません。
Android (Android TV・denpa-tv) と Linux の Chrome は FreeType の自動ヒンティング (light) で縦だけ合わせ、macOS・iOS はヒンティングをせず、
Windows のブラウザ (DirectWrite) もヒンティングの無いフォントをなめらかに描きます。字幕は 1 字 20px より大きいので、命令が無くても線は潰れません。
ttfautohint などの道具も増やしません。縦書き (vhea/vmtx) も持ちません。GPOS は下の palt だけ、GSUB は下の ccmp だけです。
